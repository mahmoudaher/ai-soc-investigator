# AI SOC Investigator

AI-assisted security operations project for organizing alerts and supporting SOC investigation workflows. It provides a TypeScript foundation for incident triage, investigation context, and analyst tooling.

## Goals

- Organize security investigation workflows.
- Present context around alerts and incidents.
- Support AI-assisted SOC analysis.
- Keep investigation features modular and extensible.

## Run Locally

```bash
npm install
npm run dev
```

Check `package.json` for the available scripts.

## Status

Early-stage security tooling prototype. Review authentication, authorization, logging, and threat modeling before production use.
